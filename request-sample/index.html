Before samples ship

What we ask for, and why.

A described part gets a matched panel and a system recommendation. A bare colour code gets a guess.

Part

What it is

Use, substrate, size and a photo or sample. This decides the system.

Environment

Where it lives

Indoor or outdoor, humidity, coastal, chemicals, temperature.

Appearance

How it looks

Colour code or sample, gloss, texture or metallic target.

Process

How you coat

Pretreatment, film thickness, spray equipment and actual cure. Usually the most useful line.
