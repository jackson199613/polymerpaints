How to prepare a colour-matching request.

A complete brief with a physical reference gives a closer first match and fewer rounds of adjustment.

When you need this

You need a new colour, want to replace a current powder, or your customer has supplied a colour sample. The more the brief describes the conditions behind the colour, the faster the panel can be approved.

Related questions

  • Can you match a RAL colour or a colour from my own sample?
  • How do you make sure repeat orders match the colour I approved?
  • What gloss levels and surface effects do you offer?

Steps

  1. Provide a physical reference

    Send a flat coated part, panel or the current powder, not only a photo or screen colour. A RAL code is useful, but add a physical reference when gloss or texture matters.

  2. State system and environment

    Say whether the part is indoor or outdoor and which system you expect, so the match is made in the right chemistry.

  3. Specify gloss and effect

    Give the gloss band or target value and the effect, for example smooth, sand texture or metallic.

  4. Describe your process

    Include substrate, pretreatment, target film thickness and actual cure conditions, since these influence colour and gloss.

  5. Agree how colour is judged

    State the light source, whether an instrument is used, and the colour-difference tolerance you or your customer accept.

  6. Add volume and timing

    Give expected quantity, reorder pattern and when you need the panel.

Parameters

Colour reference
RAL code and/or physical sample
Gloss bands
≥90 high gloss; 11–80 satin/matt; ≤10 dead matt
Colour tolerance
Agreed per project
Approved panel
Recorded as a version

Common mistakes

  • Sending only a photo or a screen colour.
  • Giving a RAL code for a metallic or textured finish without a physical sample.
  • Leaving out gloss, so the colour matches but the appearance does not.
  • Not mentioning the light source or tolerance the end customer uses.

Next step

Send your colour reference and the brief above, and we will match the colour and return a panel for approval.
